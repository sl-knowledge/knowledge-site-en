## Purpose and core mechanism

When entering a new field, first help the learner build a **representation from which they can derive implications**, so that questions grow out of a framework rather than beginning with memorized facts.

The mechanism in one line: **representation → derivation → expectation → discrepancy between expectation and reality → question → revised representation**.

Rationale: students seldom ask questions when they have no expectations and therefore no “cognitive disequilibrium” (Graesser and colleagues); self-generated material is remembered better (the generation effect, Slamecka and Graf, 1978).

## Step 0: Build an initial representation

On entering a new field, answer six questions in one or two sentences each. Gaps become the first questions.

The following spoken-English example illustrates question generation; it is not an experimental result.

| # | Question | Illustrative answer for spoken-English learning |
| --- | --- | --- |
| 1 | **State:** which variables describe the system? | Words and sentences understood, expressions actively produced, response time |
| 2 | **Constraints:** which boundaries must not be crossed? | Available time, attention, task difficulty and feedback conditions |
| 3 | **Plan:** what is the reference trajectory and its milestones? | Move from short responses in familiar situations to connected speech |
| 4 | **Controls:** what changes the state? | Listening discrimination, retrieval practice, expression substitution, dialogue and feedback |
| 5 | **Fallback:** how can learning continue when a task is temporarily out of reach? | Shorten sentences, divide the task, return to familiar situations |
| 6 | **Binding constraint:** what currently limits learning? | Failure to understand, inability to retrieve an expression, or insufficient sentence-planning time? |

Have a teacher or AI check the direction of the representation before starting the cycle.

## Five steps in the cycle

Step 0 is performed initially; thereafter each discrepancy generates questions whose answers revise the representation.

> The interactive demonstration in the original note is not embedded here. The five steps are listed below.

1. **Write a prediction first:** before acting, use the framework to state what you expect and where attention demands will peak.
2. **Observe or practice:** test the expectation with a task appropriate to current ability.
3. **Record discrepancies:** note only where expectation and reality differ.
4. **Generate questions through intersections:** cross each new variable with existing framework entries, list candidate questions, and choose one according to the order below.
5. **Ask and revise the representation:** ask a teacher or AI and write the answer back into the framework. When an upgrade is needed—for example, from a vocabulary list to an expression-generation process—return to step 0 and then resume.

## The intersection matrix and question order

Good questions often arise where two framework entries meet. After each answer, cross the new variable with existing entries.

| New variable | × Constraints | × Plan | × Controls | × Fallback |
| --- | --- | --- | --- | --- |
| Retrieval speed | Why can I recognize a word but not say it in time? | How quickly must I respond at the next stage? | Practice recognition or unaided production? | Can familiar vocabulary convey the same meaning? |
| A change of situation | Does a sentence I know still fit a differently framed question? | When should unfamiliar situations be added? | How can people, times and purposes be substituted? | Can I clarify the question first, then answer in separate clauses? |

Question order:

1. Start with questions **without whose answers later claims cannot be tested**, such as which state a control input changes.
2. Then ask questions producing **testable predictions**.
3. Leave fill-in-the-gap details until last, or look them up independently.

## Principles for teachers’ answers

How a teacher answers affects how far a student can develop.

- **Give mechanisms and models, not only conclusions:** distinguish recognizing an expression from retrieving it in time, then ask students to predict the effects of two kinds of practice.
- **Provide information students cannot derive:** for example, expressions used in real contexts. Leave the organization and testing of that information for students to work through.
- **End with a question that can be tested further:** for example, whether the same expression fits a different communicative purpose.
- **Provide a new representation when an upgrade is needed:** for example, replace a vocabulary list with “understand the question → identify the intention → retrieve expressions → organize a response.”

## Three types of questions

The framework generates three kinds of questions. Anomaly questions have the greatest leverage because they revise the framework itself rather than merely add a datum.

| Type | Trigger | Function | Language-learning example |
| --- | --- | --- | --- |
| Gap-filling | The framework has a slot but its content is unknown | Completes the framework | In which situations is this expression normally used? |
| Intersection | A new variable meets an existing entry | Extends the model | Which expressions become harder to retrieve when response time is reduced? |
| Anomaly | The framework predicts one outcome, but another occurs | Revises the framework | Why can I not produce a memorized expression when the question changes? |

## Progress indicators and checkpoints

Signs of progress include more anomaly questions, fewer empty framework slots and fewer repeated errors at the same level.

- **Proportion of anomaly questions:** an increase suggests the framework is beginning to generate predictions actively.
- **Empty framework slots:** unanswered parts of step 0’s six questions should decline across rounds.
- **Repeated errors at the same level:** when a layer—state, constraint, pattern or fallback—no longer produces errors, it has become habitual.

Check each round:

- [ ] A teacher or AI has checked the initial representation’s direction.
- [ ] A prediction was written before acting.
- [ ] Every question identifies its framework component.

**Risk:** an incorrect initial representation can send questions further off course. If discrepancies remain unexplained, redraw the representation from step 0 rather than continuing to add details.

## An illustrative walkthrough: from memorization to production

Suppose a learner expects that memorizing a set of sentences will enable the corresponding conversation. In practice, they understand the sentences when shown them but cannot respond independently when a question is rephrased.

The next question is not simply how to memorize more. It is whether the initial representation omitted retrieval speed, intention recognition and transfer across situations. In the next round, hold vocabulary difficulty constant and change only the question wording to see whether errors persist.

If the discrepancy shrinks, record which changes mattered. If it remains unexplained, keep revising the representation. This scenario illustrates how questions are generated and tested; it reports no actual classroom trial.
